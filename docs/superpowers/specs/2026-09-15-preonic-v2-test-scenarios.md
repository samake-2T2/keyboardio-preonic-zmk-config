# Keyboardio Preonic v2.0 전 기능 검증 테스트 시나리오 (E2E Test Scenario)

> **노션 페이지 링크**: [Keyboardio Preonic v2.0 전 기능 검증 테스트 시나리오 (Notion)](https://app.notion.com/p/Keyboardio-Preonic-v2-0-E2E-Test-Scenario-3dc969812b858144a68ad6cdf7da460b)

본 문서는 **Keyboardio Preonic Custom Firmware v2.0** 및 **Preonic Studio Web GUI**의 모든 기능(8개 레이어, 로터리 노브, 물리적 보안 잠금, 다이내믹 매크로, TRNG 비밀번호, 마우스 키, 키 테스터, 피에조 오디오, GitHub 실시간 연동, 원클릭 부트로더 플래싱)을 체계적으로 검증하기 위한 E2E 테스트 체크리스트입니다.

---

## 1. 테스트 준비 및 사전 환경 (Prerequisites)

- **하드웨어**: Keyboardio Preonic 키보드 (USB Type-C 케이블 연결)
- **펌웨어 바이너리**: `keyboardio_preonic__zmk.uf2` (v2.0.0)
- **웹 설정기**: `preonic-studio.html` (단일 HTML 파일)
- **권장 브라우저**: Google Chrome 또는 Microsoft Edge (Web Serial API 기본 지원)

---

## 2. 시나리오 1: USB Web Serial 연결 및 자동 키맵 동기화
- [ ] **미연결 상태 검증**: 브라우저에서 `preonic-studio.html` 실행 시 키맵 에디터가 완전히 빈 상태(점선 테두리)로 표시되는지 확인
- [ ] **안내 배너 검증**: 상단에 *"키보드가 연결되지 않았습니다. [Connect USB] 버튼을 눌러 연결하면 현재 저장된 키맵이 로드됩니다."* 문구가 표시되는지 확인
- [ ] **미연결 클릭 방지**: 연결되지 않은 상태에서 키캡 클릭 시 임의 편집 모달이 열리지 않고 안내 토스트가 뜨는지 확인
- [ ] **USB 시리얼 연결**: 우측 상단 `[Connect USB]` 버튼 클릭 -> 'Preonic' 또는 0x3496 USB CDC ACM 포트 선택 후 연결
- [ ] **핸드셰이크 검증**: 상단에 기기명 'Preonic', 펌웨어 버전 'v2.0.0', 배터리 잔량 게이지가 정상 표시되는지 확인
- [ ] **실시간 키맵 동기화**: 연결 성공 즉시 활성 레이어의 실제 키맵이 <200ms 내에 로드되고, 8개 레이어 전체가 백그라운드 캐싱되는지 확인

---

## 3. 시나리오 2: 물리적 보안 잠금 및 Fn + Z 언락 (Security)
- [ ] **초기 잠금 상태**: USB 연결 직후 상단 헤더에 `Locked (Fn + Z)` 오렌지 배지가 활성화되어 있는지 확인
- [ ] **쓰기 차단 검증**: 잠긴 상태에서 키맵 수정, 매크로 주입, 노브 저장 시도시 `STATUS_ERR_LOCKED` 에러로 차단되고 잠금 해제 안내 모달이 열리는지 확인
- [ ] **물리적 해제 (Fn + Z)**: 키보드에서 `Fn` 키(Layer 3)를 누른 채 `Z` 키(물리 40번 위치)를 누름
- [ ] **음향 피드백 검증**: 피에조 부저에서 경쾌한 상승 2음(2000Hz -> 3000Hz) 잠금 해제 멜로디가 울리는지 확인
- [ ] **시각 피드백 검증**: 버터플라이 LED 4개 날개가 앰버(주황색)로 2회 반짝이는지 확인
- [ ] **실시간 UI 전환**: Web Studio가 `EVT_UNLOCKED` 이벤트를 수신하여 `Unlocked` 녹색 배지로 자동 전환되는지 확인
- [ ] **수동 잠금 검증**: `[Lock Now]` 버튼 클릭 시 하강 2음 멜로디(3000Hz -> 2000Hz)와 함께 즉시 다시 잠기는지 확인
- [ ] **300초 무입력 자동 잠금**: 300초(5분) 동안 호스트 명령이 없을 경우 키보드가 스스로 다시 잠기는지 확인

---

## 4. 시나리오 3: 8개 레이어 네비게이션 & 듀얼 액션 (Tap-Hold)
- [ ] **Layer 0 (Base)**: 5x12 MIT 오쏘리니어 기본 타이핑 (문자 A~Z, 숫자 0~9, 2u 스페이스바, Enter, Backspace, Modifiers)
- [ ] **Layer 1 (Lower)**: `Lower` 키 홀드 시 기호 및 넘패드 레이어 활성화, 단타(Tap) 시 정상 Space 또는 Nav 출력
- [ ] **Layer 2 (Raise)**: `Raise` 키 홀드 시 특수문자, 괄호 쌍, F1~F12 기능키 정상 입력
- [ ] **Layer 3 (Func)**: `Fn` 키 홀드 시 BLE 프로필 전환, 사운드 토글, 배터리 게이지 단축키 활성화
- [ ] **Layer 4 (Tri-Layer)**: `Lower` 키와 `Raise` 키를 동시에 누를 때 Tri-Layer로 자동 전환되는지 확인
- [ ] **Layer 5, 6, 7 (Extra 1, 2, 3)**: `&to 5`, `&tog 6`, `&mo 7` 등으로 5~7번 확장 레이어로 전환 및 복귀가 매끄럽게 동작하는지 확인
- [ ] **듀얼 액션 탭-홀드**: `&lt` (Layer-Tap) 및 `&mt` (Mod-Tap) 키를 빠르게 탭하면 기본 키코드, 길게 누르면 모디파이어/레이어로 정확히 분기되는지 확인

---

## 5. 시나리오 4: 로터리 인코더 노브 8개 레이어 독립 설정
- [ ] **8개 레이어 버튼 표시**: Tab 3 (Rotary Knob)에서 0번(Base)부터 7번(Extra 3)까지 8개 레이어 버튼이 모두 표시되는지 확인
- [ ] **Layer 0 노브 설정**: CW = Volume Up, CCW = Volume Down, PPD = 2 설정 후 `[Apply Knob Settings]` 클릭
- [ ] **Layer 1 노브 설정**: CW = Mouse Scroll Up, CCW = Mouse Scroll Down, PPD = 4 설정 후 `[Apply Knob Settings]` 클릭
- [ ] **레이어 전환 시 설정 연동**: Layer 0과 Layer 1 버튼을 번갈아 클릭할 때 드롭다운과 슬라이더가 각 레이어의 저장값으로 즉각 갱신되는지 확인
- [ ] **하드웨어 감도 체감**: PPD 슬라이더를 2에서 8로 올렸을 때 실제 노브를 돌릴 때 더 많은 클릭을 회전해야 1회 동작이 발생하는지 확인
- [ ] **키보드 재연결 & NVS 유지**: 키보드 USB를 뺐다 꽂은 후 `[Read Knob Settings]` 클릭 시 변경했던 노브 설정이 영구 보존되어 있는지 확인

---

## 6. 시나리오 5: 다이내믹 텍스트 매크로 매니저 (Macro)
- [ ] **슬롯 텍스트 주입**: Slot 1 선택 후 텍스트 입력창에 `echo Hello Preonic v2.0!` 입력 후 `[Save Macro to Keyboard]` 클릭
- [ ] **웹에서 재생 테스트**: 메모장이나 텍스트 에디터를 활성화한 후 `[Play Macro on Keyboard]` 클릭 -> 즉시 타이핑되는지 확인
- [ ] **키보드 단축키 재생**: 물리 키보드에서 `Fn + 5` (Slot 1 단축키) 입력 시 동일하게 텍스트가 자동 타이핑되는지 확인
- [ ] **다중 슬롯 검증**: Slot 2, Slot 3에도 각각 다른 텍스트를 저장하고 `Fn + 6`, `Fn + 7`로 각각 독립 재생되는지 확인
- [ ] **PC 백업 & 복원**: `[Backup Macros (.json)]` 클릭하여 JSON 파일로 저장 후, 내용을 비우고 `[Restore Macros (.json)]`으로 복원되는지 확인

---

## 7. 시나리오 6: 하드웨어 TRNG 비밀번호 생성기 (Password Gen)
- [ ] **설정 변경**: 길이 버튼(12, 16, 20, 24자 중 20자 선택) 및 커스텀 특수문자 입력 후 `[Save Password Config]` 클릭
- [ ] **Default 비밀번호 타이핑**: 메모장을 열고 물리 키보드에서 `Fn + D` 입력 -> 대/소문자, 숫자, 특수문자가 조합된 20자리 안전한 비밀번호가 타이핑되는지 확인
- [ ] **Web Safe 비밀번호**: 키보드에서 `Fn + W` 입력 -> URL 및 웹 입력창에 적합한 영문+숫자 비밀번호가 생성되는지 확인
- [ ] **Alpha Only 비밀번호**: 키보드에서 `Fn + A` 입력 -> 특수문자가 제외된 순수 영문 비밀번호가 생성되는지 확인
- [ ] **타이핑 딜레이 조절**: 슬라이더를 12ms에서 30ms로 조절 후 저장 -> 타이핑 속도가 안정적으로 부드러워지는지 확인

---

## 8. 시나리오 7: 마우스 커서 이동 및 스무스 스크롤 키 (Mouse)
- [ ] **키 바인딩 매핑**: 키맵 에디터에서 특정 레이어(예: Raise)의 방향키 자리에 Mouse Keys 카테고리의 Move Up/Down/Left/Right 매핑
- [ ] **스크롤 키 매핑**: 인접 키에 Scroll Up/Down/Left/Right 매핑 후 `[Save Keymap to Flash]` 클릭
- [ ] **커서 이동 테스트**: 해당 레이어로 전환 후 키를 누르면 PC 화면의 마우스 포인터가 상하좌우로 부드럽게 가속하며 움직이는지 확인
- [ ] **스크롤 테스트**: 웹 브라우저 창에서 스크롤 키를 누르면 마우스 휠을 굴린 것처럼 페이지가 부드럽게 상하좌우 스크롤되는지 확인
- [ ] **가속도 파라미터 튜닝**: Tab 5에서 Time to Max 및 Acceleration Exponent 슬라이더를 변경하여 본인 취향의 마우스 속도로 저장되는지 확인

---

## 9. 시나리오 8: 스위치 매트릭스 & 채터링 키 테스터 (Tester)
- [ ] **테스터 화면 진입**: Tab 7 (Key Tester)로 이동하여 62개 키의 초기 상태가 회색으로 대기 중인지 확인
- [ ] **전체 키 순차 입력**: 키보드의 62개 키를 좌측 상단부터 우측 하단까지 빠짐없이 하나씩 누름
- [ ] **실시간 반응 확인**: 누르고 있는 동안 파란색(key-pressing), 뗀 후 청록색(key-tested)으로 기록되는지 확인
- [ ] **테스트 카운터 확인**: Tested Keys 카운터가 누를 때마다 올라가 최종 62 / 62에 도달하는지 확인
- [ ] **채터링 진단 확인**: 스위치 접점 바운스가 15ms 이내로 정상인지(Chatter Status: Clean) 확인
- [ ] **리셋 버튼 동작**: `[Reset Tester]` 클릭 시 모든 키캡이 초기화되고 카운터가 0 / 62로 리셋되는지 확인

---

## 10. 시나리오 9: 오디오 피에조 & 하드웨어 텔레메트리 (Audio)
- [ ] **Master Sound 음소거**: Master Sound를 OFF로 끄고 저장 -> 잠금 해제 사운드, 부트로더 사운드가 전혀 울리지 않는지 확인
- [ ] **Clicky Sound 피드백**: Clicky Sound를 ON으로 켜고 저장 -> 물리 키를 누를 때마다 경쾌한 기계식 틱 사운드가 스피커에서 발생하는지 확인
- [ ] **주파수 조절 테스트**: 주파수 슬라이더(1000Hz ~ 6000Hz) 조절 후 `[Play Test Tone]` 클릭 -> 키보드에서 해당 음높이의 비프음이 즉시 울리는지 확인
- [ ] **텔레메트리 실시간 확인**: 상단 배터리 게이지 및 Tab 6에서 현재 배터리 전압(mV), 잔여 백분율(%), 선택된 BLE 프로필 번호가 실시간 갱신되는지 확인

## 11. 시나리오 10: GitHub 실시간 연동 & 원클릭 부트로더 플래싱 (Update)
- [ ] **상단 깃허브 배지**: 상단 우측에 🐙 GitHub 배지가 표시되고 최신 상태일 때 `GitHub: v2.0.0 ✓` 녹색으로 점등되는지 확인
- [ ] **배지 클릭 전환**: 🐙 GitHub 배지를 클릭하면 Tab 8 (Firmware & Updates) 화면으로 자동 전환되는지 확인
- [ ] **버전 비교 카드**: Installed Firmware(v2.0.0)와 Latest Release(v2.0.0)가 비교되어 'Up to Date' 배너가 정상 표시되는지 확인
- [ ] **최근 커밋 로그**: master 브랜치의 최근 커밋 6개의 메시지, 단축 해시(eb9c958 등), 상대 시간 타임라인이 올바르게 로드되는지 확인
- [ ] **펌웨어 직접 다운로드**: `[Download keyboardio_preonic__zmk.uf2]` 버튼 클릭 시 최신 컴파일 바이너리가 PC로 정상 다운로드되는지 확인
- [ ] **원클릭 부트로더 진입**: `[⚡ Reboot Keyboard to Bootloader]` 버튼 클릭 -> 확인 팝업 승인 -> 키보드가 즉시 DFU 모드로 재부팅되어 PC에 'PREONIC' USB 드라이브가 마운트되는지 확인
- [ ] **드래그 & 드롭 플래싱**: 다운로드한 `.uf2` 파일을 PREONIC 드라이브로 복사 -> 드라이브가 자동 언마운트되고 키보드가 최신 펌웨어로 2초 내 재부팅되는지 확인
